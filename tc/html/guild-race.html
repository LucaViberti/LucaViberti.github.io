Overview

公會競賽是遊戲的主要活動之一。儘量獲得更多榮譽積分，榮譽商店是遊戲中最值得購買的商店之一。 完成任務即可得分。開始時免費獲得9張任務券，每天還能購買15張。建議每天至少購買前5張，因為總價僅300鑽石。之後10張每張300鑽石。如果有足夠任務可做，最好是金色任務，也可以繼續購買。榮譽商店的價值很高，多買任務券值得。建議公會提醒成員：只有能迅速完成時才接任務。若有人把訓練士兵任務佔用數小時，會拖慢整個公會。 你有2個只有自己能用的專屬任務。每10分鐘可免費重新整理其中一個。也可花100鑽石跳過冷卻，但不推薦：成本和刷到目標任務的機率不值得，不如購買更多工券。多數專屬任務所需資源更少，例如專屬訓練任務只需400名士兵，公會任務需要500名。也可以提前準備任務：免費刷到稍後需要的任務後保留，繼續重新整理另一個。伺服器重置時專屬任務會更新；若要留到重置後，先接受該任務。這樣重置後仍保留，之後放棄，它仍會回到專屬工作列，適合為次日做準備。 刷到合適任務往往需要運氣，所以不宜只做專屬任務。應找到適合自己的方式，儘可能完成更多金色任務。願意付費的玩家可以購買任務選擇券，讓競賽更輕鬆：你會獲得第3個專屬任務位置，可用券選擇所需任務。注意：任務選擇券只用於金色任務。 不是所有任務都適合公會競賽。不要浪費任務券做藍色任務，紫色任務很容易完成，積分卻是藍色的3倍。最好只做金色任務，它們積分最高。

Tasks you should use in guild race

  • 士兵訓練任務（只做金色任務。最容易完成的任務之一，每天至少能完成2次）。
  • 建築任務（只做金色任務。建築完成後先不要領取，等任務出現。很適合等待專屬金色任務）。
  • 研究任務（前中期較難，因為1至2項研究往往不足以提供任務要求的提升。後期單項研究耗時數天，但獲得的影響力足夠一次完成任務。務必提前準備，否則研究完成後等待任務會浪費大量研究時間）。
  • 消耗鑽石任務（只做專屬任務，儘可能選金色。每週有很多需要用鑽石購買的物品，等接到任務後再購買。先買當天需要的物品，再從周商店補足任務要求）。
  • 購買禮包鑽石（付費玩家應等到此任務再購買。這是唯一比其他同色金色或紫色任務給更多積分的任務，只出現在專屬工作列。購買前確認能完成；若購買不到1600鑽石，做紫色任務比浪費金色任務更好）。
  • 發起集結並擊殺首領（只有紫色任務。任務券太多、想多做一些任務時，這是簡單的選擇）。
  • 擊殺世界地圖怪物（只有紫色任務。最簡單，也是唯一可不消耗資源完成的任務。加入集結即可完成，不需要額外資源。與上一任務一樣，只在還有任務券且無法完成金色任務時使用）。

A bit later in the early game

前期稍後也會出現以下任務，但僅在專屬工作列出現，積分比普通金色任務略高。

  • 消耗傳說遺物碎片（第3、4天出現。只做金色任務。保留傳說遺物碎片，僅在公會競賽接到此任務時使用）。
  • 消耗魔法石（第3、4天的專屬任務。只做金色任務。保留魔法石，僅在公會競賽接到任務時使用。也可在交易商店的資源頁用魔法石兌換奧術水晶來完成。奧術水晶總是短缺，因此推薦兌換，每週至少能完成3次這類任務）。
  • 使用勳章（第5、6、7天的專屬任務。只做金色任務。保留勳章，在公會競賽與任務配合使用。唯一例外是勳章商店：沒有公會競賽的周，也可以兌換加速）。
  • 提升領主裝備戰力（第5、6、7天的專屬任務。只做金色任務。把領主裝備升級留到公會競賽接到任務時，其他日子不要升級。提示：3件或6件領主裝備達到同一級別會啟用加成，僅加成帶來的戰力提升就可能完成一個任務。利用這一點，升級一件裝備啟用加成即可完成）。

可以完成，但建議留到軍備競賽或王國對戰的任務

  • 使用研究或建築加速（不推薦，此任務需要消耗太多加速，不如做簡單的紫色任務）。
  • 消耗傳說碎片（若急需升級英雄可以做，但更推薦留到軍備競賽或王國對戰）。

Task you should NEVER use

  • 酒館招募英雄（只有紫色任務，因此建議不要做。擊殺怪物也能得到相同榮譽積分，應把酒館招募券留給軍備競賽和王國對戰）。

Rewards

每週個人和公會榮譽積分還會提供額外獎勵。每次公會競賽應爭取至少7000分以獲得最高獎勵（第1賽季研究之前，最高獎勵門檻為6000分）。投入一些時間就能輕鬆超過10000分。儘量多得分，就能在榮譽商店買更多物品。若每天至少購買前5張任務券，本週就能完成44個任務。

第1賽季的世界樹之影研究分支中，有兩項非常適合公會競賽的升級。

第一項增加個人6500與7000榮譽積分，以及公會65000與70000積分的獎勵。第二項位於研究樹稍下方，可增加每個已完成任務的榮譽積分。應儘快取得這兩項升級。

What you can buy in the honour shop

榮譽商店中部分重要物品會在遊戲稍後階段加入：

  • 靈魂石／6000榮譽積分（始終購買自己主力陣營的靈魂石。對免費玩家，這是英雄靈魂石的主要來源）。
  • 通用士兵皮膚／傳說12000榮譽積分／史詩1200榮譽積分
  • 傳說通用英雄碎片／每片300分
  • 通用專屬裝備碎片／每片400分
  • 傳說通用遺物碎片／每片800分
  • 龍之精華／每個120分（後期需求很大，這裡是補充來源之一）。
