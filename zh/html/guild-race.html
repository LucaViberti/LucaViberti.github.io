Overview

公会竞赛是游戏的主要活动之一。尽量获得更多荣誉积分，荣誉商店是游戏中最值得购买的商店之一。 完成任务即可得分。开始时免费获得9张任务券，每天还能购买15张。建议每天至少购买前5张，因为总价仅300钻石。之后10张每张300钻石。如果有足够任务可做，最好是金色任务，也可以继续购买。荣誉商店的价值很高，多买任务券值得。建议公会提醒成员：只有能迅速完成时才接任务。若有人把训练士兵任务占用数小时，会拖慢整个公会。 你有2个只有自己能用的专属任务。每10分钟可免费刷新其中一个。也可花100钻石跳过冷却，但不推荐：成本和刷到目标任务的概率不值得，不如购买更多任务券。多数专属任务所需资源更少，例如专属训练任务只需400名士兵，公会任务需要500名。也可以提前准备任务：免费刷到稍后需要的任务后保留，继续刷新另一个。服务器重置时专属任务会更新；若要留到重置后，先接受该任务。这样重置后仍保留，之后放弃，它仍会回到专属任务栏，适合为次日做准备。 刷到合适任务往往需要运气，所以不宜只做专属任务。应找到适合自己的方式，尽可能完成更多金色任务。愿意付费的玩家可以购买任务选择券，让竞赛更轻松：你会获得第3个专属任务位置，可用券选择所需任务。注意：任务选择券只用于金色任务。 不是所有任务都适合公会竞赛。不要浪费任务券做蓝色任务，紫色任务很容易完成，积分却是蓝色的3倍。最好只做金色任务，它们积分最高。

Tasks you should use in guild race

  • 士兵训练任务（只做金色任务。最容易完成的任务之一，每天至少能完成2次）。
  • 建筑任务（只做金色任务。建筑完成后先不要领取，等任务出现。很适合等待专属金色任务）。
  • 研究任务（前中期较难，因为1至2项研究往往不足以提供任务要求的提升。后期单项研究耗时数天，但获得的影响力足够一次完成任务。务必提前准备，否则研究完成后等待任务会浪费大量研究时间）。
  • 消耗钻石任务（只做专属任务，尽可能选金色。每周有很多需要用钻石购买的物品，等接到任务后再购买。先买当天需要的物品，再从周商店补足任务要求）。
  • 购买礼包钻石（付费玩家应等到此任务再购买。这是唯一比其他同色金色或紫色任务给更多积分的任务，只出现在专属任务栏。购买前确认能完成；若购买不到1600钻石，做紫色任务比浪费金色任务更好）。
  • 发起集结并击杀首领（只有紫色任务。任务券太多、想多做一些任务时，这是简单的选择）。
  • 击杀世界地图怪物（只有紫色任务。最简单，也是唯一可不消耗资源完成的任务。加入集结即可完成，不需要额外资源。与上一任务一样，只在还有任务券且无法完成金色任务时使用）。

A bit later in the early game

前期稍后也会出现以下任务，但仅在专属任务栏出现，积分比普通金色任务略高。

  • 消耗传说遗物碎片（第3、4天出现。只做金色任务。保留传说遗物碎片，仅在公会竞赛接到此任务时使用）。
  • 消耗魔法石（第3、4天的专属任务。只做金色任务。保留魔法石，仅在公会竞赛接到任务时使用。也可在交易商店的资源页用魔法石兑换奥术水晶来完成。奥术水晶总是短缺，因此推荐兑换，每周至少能完成3次这类任务）。
  • 使用勋章（第5、6、7天的专属任务。只做金色任务。保留勋章，在公会竞赛与任务配合使用。唯一例外是勋章商店：没有公会竞赛的周，也可以兑换加速）。
  • 提升领主装备战力（第5、6、7天的专属任务。只做金色任务。把领主装备升级留到公会竞赛接到任务时，其他日子不要升级。提示：3件或6件领主装备达到同一级别会激活加成，仅加成带来的战力提升就可能完成一个任务。利用这一点，升级一件装备激活加成即可完成）。

可以完成，但建议留到军备竞赛或王国对战的任务

  • 使用研究或建筑加速（不推荐，此任务需要消耗太多加速，不如做简单的紫色任务）。
  • 消耗传说碎片（若急需升级英雄可以做，但更推荐留到军备竞赛或王国对战）。

Task you should NEVER use

  • 酒馆招募英雄（只有紫色任务，因此建议不要做。击杀怪物也能得到相同荣誉积分，应把酒馆招募券留给军备竞赛和王国对战）。

Rewards

每周个人和公会荣誉积分还会提供额外奖励。每次公会竞赛应争取至少7000分以获得最高奖励（第1赛季研究之前，最高奖励门槛为6000分）。投入一些时间就能轻松超过10000分。尽量多得分，就能在荣誉商店买更多物品。若每天至少购买前5张任务券，本周就能完成44个任务。

第1赛季的世界树之影研究分支中，有两项非常适合公会竞赛的升级。

第一项增加个人6500与7000荣誉积分，以及公会65000与70000积分的奖励。第二项位于研究树稍下方，可增加每个已完成任务的荣誉积分。应尽快取得这两项升级。

What you can buy in the honour shop

荣誉商店中部分重要物品会在游戏稍后阶段加入：

  • 灵魂石／6000荣誉积分（始终购买自己主力阵营的灵魂石。对免费玩家，这是英雄灵魂石的主要来源）。
  • 通用士兵皮肤／传说12000荣誉积分／史诗1200荣誉积分
  • 传说通用英雄碎片／每片300分
  • 通用专属装备碎片／每片400分
  • 传说通用遗物碎片／每片800分
  • 龙之精华／每个120分（后期需求很大，这里是补充来源之一）。
